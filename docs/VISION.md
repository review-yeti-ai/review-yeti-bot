# Vision

> [!WARNING]
> **Aspirational design record; non-authoritative.** This document describes product direction, not
> current Action behavior, provider routing, release state, or central fleet policy. See
> [Documentation authority](DOCUMENTATION_AUTHORITY.md).

Review responsibility belongs to repository-configured teams, not a generic
model prompt. Persona lanes surface domain findings, distinct providers reduce
correlated blind spots, a moderator creates a coherent ledger, and a separate
arbiter makes the binding disposition.

The public result must be inspectable: exact SHA, actual provider/model,
required-lane coverage, quorum, moderator ledger, arbiter verdict, and native
`ct-review-bot[bot]` authorship.

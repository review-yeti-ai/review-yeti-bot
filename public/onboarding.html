How to Register a GitHub App for your Organization

CT Review Bot integrates with GitHub using an official GitHub App. This provides fine-grained permissions, webhook security, and high API rate limits (5,000 req/hr per installation).

1Open your GitHub Organization Settings: https://github.com/organizations/YOUR_ORG/settings/apps/new
2Fill in GitHub App Name (e.g. ct-review-bot-app) and set Webhook Target URL to https://api.calltelemetry.com/api/webhooks/github.
3Set Permissions: Pull Requests (Write), Issues (Write), Checks (Write), Contents (Read).
4Generate and download the Private Key (.pem file), then copy the App ID and Installation ID back into Step 1 of this wizard.
